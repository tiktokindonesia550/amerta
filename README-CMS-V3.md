## Menambah publikasi terbaru
Admin > Bukti Publikasi > Daftar Publikasi > tambah item.
Isi judul, link artikel, media, kategori, tanggal tayang, ringkasan, dan logo media bila tersedia.

## Menambah artikel SEO
Admin > Artikel / Insight > Artikel.
