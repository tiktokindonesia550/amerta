# AMERTA Website

Website corporate premium untuk AMERTA. Dibuat sebagai static site sehingga bisa langsung dideploy ke Vercel tanpa backend.

## Struktur

- index.html
- styles.css
- app.js
- assets/amerta-logo.png

## Deploy ke Vercel

1. Upload folder ini ke GitHub.
2. Buka Vercel.
3. Import repository.
4. Framework Preset: Other.
5. Build Command: kosongkan.
6. Output Directory: .
7. Deploy.

Alternatif: jalankan `npx vercel` dari folder project.
