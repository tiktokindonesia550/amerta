# AMERTA Website V2

Fokus:
- Homepage conversion
- Visual newsroom portfolio
- 139 unique publication references from supplied AMERTA source
- Sector pages
- SEO / Insight section
- Decap CMS for case studies and articles
- Mobile-first responsive UI for Android and iPhone
- Real media logo assets referenced from verifiable sources

CMS:
1. Push repository to GitHub.
2. In admin/config.yml set repo.
3. Configure GitHub OAuth endpoint for Decap CMS.
4. Open /admin/ after deployment.
5. Add/edit case studies and SEO articles from the CMS. The team does not need to edit HTML/JS.

Important:
- Replace YOUR_GITHUB_USERNAME/YOUR_AMERTA_REPOSITORY in admin/config.yml.
- Replace YOUR-AMERTA-DOMAIN.vercel.app in site_url, robots.txt and sitemap.xml.
- The logo URLs in the site use verifiable media logo sources. For commercial use, verify each media's current logo usage permission/brand policy before publishing.
