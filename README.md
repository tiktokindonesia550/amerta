# AMERTA Website

Website landing page statis untuk AMERTA. Siap di-deploy ke Vercel tanpa build step.

## Deploy ke Vercel
1. Upload folder project ini ke GitHub, atau import repository ke Vercel.
2. Framework preset: Other / Static.
3. Build command: kosong.
4. Output directory: .
5. Deploy.

## File
- index.html
- public/amerta-logo.png

## Catatan
- Tombol CTA langsung membuka WhatsApp AMERTA.
- Contoh publikasi menggunakan daftar publikasi yang diberikan.
- Logo dipotong dari asset AMERTA yang diberikan, tanpa membuat logo baru.
