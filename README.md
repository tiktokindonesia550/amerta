# AMERTA Website

Website corporate premium untuk deploy langsung ke Vercel.

## Struktur
- index.html
- assets/amerta-logo-transparent.png
- assets/*.svg

## Deploy ke Vercel
1. Upload folder ini ke GitHub.
2. Import repository ke Vercel.
3. Framework Preset: Other.
4. Build Command: kosong.
5. Output Directory: .
6. Deploy.

Tidak membutuhkan database atau backend.
